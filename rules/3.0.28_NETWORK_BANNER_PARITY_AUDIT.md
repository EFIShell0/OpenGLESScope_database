# OpenGLESScope Database 3.0.28 — network banner parity audit

## Reference
The shared behavior and geometry reference is the frozen VulkanScope Database 1.4.12 material already shipped in this source tree, including `SHARED_UI_1_4_12_REFERENCE.css` and the corresponding engineering-rule reference.

## Defect 1 — false restored notification on normal startup
OpenGLESScope uses a verified cache-first startup. In 3.0.27, the experience layer interpreted `isVerifiedOffline()` during `openglesscope:ready` as a real network interruption. When the background Worker probe subsequently succeeded, the reconnect latch was still set and the UI displayed **Connection restored** on an ordinary online page open.

### 3.0.28 correction
- Keep the verified cache-first render unchanged.
- Do not set the reconnect latch merely because startup is currently rendering the verified local snapshot.
- Preserve true offline/error handling and the real browser reconnect recheck path.
- Keep Worker/API success authoritative for live reachability.

## Defect 2 — mobile banner misalignment
The shared 760 px rules already matched the VulkanScope reference, but a later OpenGLESScope-only tail rule redefined `.network-status-shell.is-visible` to 150 px and redefined `.network-status-banner` to 58 px. Because those rules appeared later, they overrode the mobile 96 px / 82 px geometry.

### 3.0.28 correction
The two late common-geometry overrides are removed. The shared reference rules are again authoritative:
- mobile body offset: 82 px;
- visible shell ceiling: 96 px;
- banner minimum height: 82 px;
- narrow compact breakpoint: 470 px, including hidden status badge.

## Preserved contracts
OpenGLESScope 3.0.7 / 3007 remains the exact new-report producer. No D1 migration, stored-report rewrite, schema/technicalReport/normalizer change, GL/EGL evidence change, cache-first snapshot-format change, privacy change or security relaxation is part of this release.

## Release blocker
`tools/test_3_0_28_network_banner_parity.py` verifies the startup/reconnect state-machine guard and exact frozen mobile geometry, and `tools/quality_gate.py` executes it with the existing complete release gates.
