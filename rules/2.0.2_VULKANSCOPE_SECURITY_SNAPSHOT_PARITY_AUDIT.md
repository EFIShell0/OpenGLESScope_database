| Shared UI surface | Existing 16 domain-specific workspaces, four Settings sections, regional preferences, pagination and reduced-motion controls retain regression tests. |

## Deliberate differences, not missing Vulkan capabilities

- VulkanScope 1.4.12 builds a public, chunked static full-report preload from its Worker. OpenGLESScope publishes an allowlisted **summary-only** Pages snapshot; complete submitted GL/EGL reports remain retrievable through the exact report-ID Worker API. This reduces indiscriminate static duplication of full technical evidence, especially historical submissions. The user-facing report content is not invented or dropped, but the preload delivery optimization is not identical.
- OpenGLESScope Internet request/route diagnostics fetch only on explicit user activation; VulkanScope can update its Internet panel while it is open. The difference intentionally avoids passive IP disclosure in the GL page.
- Vulkan-specific physical-device, queue, profile and Vulkan registry semantics cannot be copied into OpenGL ES/EGL. The GL reference catalog explicitly does not establish runtime support.
- Release/Pages and Worker correctness are verified locally. A live Cloudflare D1 migration, GitHub credential permission, public Pages deployment and independent cross-browser matrix must still be validated in the actual account before a production equivalence claim.
