# OpenGLESScope Database 0.7.0

Public report browser and Cloudflare Worker API for explicitly submitted OpenGLESScope capability reports.

## Current contract

- Database: 0.7.0
- Current producer: OpenGLESScope 0.7.0 / versionCode 700
- Submission schema: 2
- Current producer technicalReport: 2
- Compatible historical technicalReport: 1
- Normalizer: 10
- Request/report limit: 2 MiB
- Current frontend JavaScript: `app.v070.js`
- Current frontend CSS: `site.v070.css`

OpenGL ES, GLSL ES and EGL runtime evidence is stored as submitted. The Database does not infer graphics capability from GPU model, vendor branding or synthetic hardware IDs.

## EGL 0.7.0 support

Current reports include structured EGL runtime/context/surface evidence and expanded EGL Config data. Worker validation is fail-closed for the current producer and checks prerequisite extension evidence for extension-defined config attributes. Historical reports remain readable without rewriting their original payloads.

## Security and deployment

The Worker retains origin pinning, bounded JSON reading, recursive sensitive-field rejection, stable canonical JSON hashing, parameterized D1 queries and server-authored pagination. GitHub Pages deploys only the allow-listed staged artifact generated by repository tooling.

No D1 migration is required for 0.7.0.
