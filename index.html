Regional date & time

Choose Automatic, Country, or Manual presentation. Automatic uses this browser/system. Country applies the selected country’s regional date/clock conventions and a representative IANA time zone (for multi-zone countries) while locking granular overrides. Manual keeps Country / region locked to browser/system and enables only the explicit date, clock, time-zone and seasonal-offset overrides. These settings change presentation only; sorting, age filters, comparison identity and stored report timestamps remain unchanged.

Browser/system display preview. Stored evidence is never modified.
